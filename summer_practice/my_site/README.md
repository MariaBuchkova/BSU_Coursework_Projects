# Personal Introduction Website

A simple multi-page personal website created as part of the summer internship to demonstrate the knowledge and skills acquired during the HTML course.

The website presents basic information about me, including my birthplace, education, and hobbies. The project consists of several interconnected HTML pages with local images used to illustrate the content.

## Website Structure

The website contains the following pages:

- `index.html` — main introduction page
- `birthplace.html` — information about my birthplace
- `study.html` — information about my education
- `hobbies.html` — information about my hobbies

The pages are connected through internal HTML links, allowing navigation between different sections of the website.

## Features

- Multi-page HTML website
- Navigation between pages using hyperlinks
- Local images integrated into web pages
- Structured content using HTML elements
- Basic page formatting and layout
- Personal information presented across separate pages

## Images

The project uses local image files stored in the same directory:

- `MGOL.png` — personal image
- `mogilev.jpg` — image related to my birthplace
- `hobby.jpg` — image related to my hobby

## Technologies

- HTML
- Hyperlinks
- Images
- Basic Web Page Structure

# Summer Practice

This repository contains project materials and individual assignments completed as part of the **summer internship at FAMCS, Belarusian State University**.

The **main part of the internship** was the development of a **cross-platform network game "Warships"** as a team project. The repository also contains several individual assignments completed during the internship, as well as presentation and report materials related to the main project.

---

## Main Project

### Warships — Cross-Platform Network Game

The main project of the summer internship was the development of a **cross-platform network version of the classic Battleship game**.

The project was developed as a team and includes a graphical user interface, client-server interaction, game logic, and additional game functionality.

### Project repository

[**Warships-game — GitHub**](https://github.com/VladKoBY07/Warships-game)

### My contribution

My main area of responsibility was the **graphical interface and integration of UI components with the existing application logic**.

- Developed and integrated game screens, control windows, and interactive UI elements using **Qt/QML**.
- Worked with the existing screen-loading and navigation system and connected UI controls with the game logic and server-side functionality.
- Implemented UI animations and transitions, including the battlefield loading transition and screen-dimming effects.
- Redesigned the main menu, added missing control windows, and implemented animated pop-up elements.
- Improved responsive layouts and adaptive sizing of interface elements.

## Individual Assignments

Alongside the main team project, several individual tasks were completed to demonstrate practical skills acquired during the internship.

### Personal Introduction Website

A simple multi-page HTML website created to demonstrate the knowledge and skills acquired during the **HTML course**.

The website contains several interconnected pages with information about me, my birthplace, education, and hobbies. It also demonstrates the use of hyperlinks and local images.

[**Open project**](https://github.com/maria11-lab/bsu_repo/tree/main/summer_practice/my_site)

### Python Web Scraper

A command-line web scraper written in Python.

The application accepts a URL, downloads the web page, parses its HTML structure using **BeautifulSoup**, extracts text from a specified HTML tag, and saves the result to a text file.

The project demonstrates working with HTTP requests, HTML parsing, command-line arguments, exception handling, and file processing.

[**Open project**](https://github.com/maria11-lab/bsu_repo/tree/main/summer_practice/scaler_py)

# BSU Coursework & Projects

This repository contains my **university coursework, practical assignments, laboratory works, and projects** completed during my studies at the **Faculty of Applied Mathematics and Computer Science, Belarusian State University**.

It documents my progression from early programming exercises and fundamental algorithms to larger projects involving **C++, Qt/QML, software architecture, numerical methods, Java, Python, and other areas of computer science**.

Some projects are small academic assignments created to practice a particular concept, while others are more complete applications developed as independent or team projects.

---

## About the Repository

The repository is organized primarily by **semester and subject**, so that related coursework stays together and the development of my skills can be followed over time.

The earlier sections contain foundational programming exercises and university assignments, while later coursework includes more structured projects and applications.

The repository intentionally preserves some of my older and simpler projects. They represent the actual stages of my learning rather than polished rewrites of everything using modern techniques.

## Learning Progression

This repository is also a record of how my approach to programming has changed throughout my studies.

The earliest projects focus mostly on **basic syntax, algorithms, pointers, dynamic memory, and manual implementation of data structures**.

Later projects introduce **OOP, STL, design patterns, GUI development, Qt/QML, numerical algorithms, and more structured software design**.

The more recent projects place greater emphasis on **application architecture, user interfaces, integration between components, and working on larger team-based projects**.

This repository contains a mixture of **academic assignments, experiments, and larger projects**. Some older projects are intentionally kept in their original form and may not follow the coding style or architectural approaches I use today.

# Computer Graphics

University practical works and laboratory assignments in **Computer Graphics** completed as part of the university curriculum.

This section contains practical applications developed to study the fundamental principles of computer graphics, color representation and processing, as well as algorithms and methods used when working with graphical data.

Unlike small standalone tasks, the laboratory works are presented as independent applications with graphical user interfaces. Each work focuses on a specific topic of the course and includes source code, implementation details, and examples of the program in operation.

## Featured works

### [**Image_inspector**](https://github.com/MariaBuchkova/BSU_Coursework_Projects/tree/main/semester_3/computer_graphics_css/Image_inspector_lab2)

An image analysis tool focused on multithreaded file processing and efficient work with large collections of images. The project uses parallel processing, thread-safe progress tracking and cooperative cancellation to handle multiple files without blocking the application.

It also explores low-level binary data processing: reading files byte by byte, parsing format-specific structures, handling different byte orders, and extracting metadata from PNG, JPEG, GIF, BMP, TIFF and PCX files.

# Search Trees

A collection of practical assignments focused on **Binary Search Trees** as part of the university Algorithms course.

## Future Work

### 🔹 [0_main_max_imbalance](https://github.com/MariaBuchkova/BSU_Coursework_Projects/tree/main/semester_3/algorithms/search_trees/0_main_max_imbalance)

**Task:** in a binary search tree, find the vertices for which the heights of the left and right subtrees differ the most. If there is a median by key among them, delete it (right deletion) and print the pre-order traversal of the resulting tree.

**Approach:**
- **Binary Search Tree** with recursive calculation of subtree heights.
- **In-order traversal** to collect the candidates already sorted by key, so the median is the middle element.

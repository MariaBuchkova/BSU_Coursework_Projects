# Early C++ Projects

A collection of very early C++ projects created during the initial stages of my programming studies.

These projects were developed several years ago as introductory practical assignments while I was learning the fundamentals of **C++ and basic data structures**.

The projects focus on simple console-based implementations and were created primarily for learning purposes. They represent an early stage of my programming experience and are kept in the repository as part of my academic and technical progression.

The code is intentionally preserved in its original, simple form rather than being rewritten using more modern approaches.

The main purpose of these projects was to learn the fundamentals of **C++, algorithms, data structures, pointers, and manual memory management**.
